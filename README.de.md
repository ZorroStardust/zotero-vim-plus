[English](README.md) · [简体中文](README.zh-CN.md) · [Español](README.es-ES.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Français](README.fr.md) · [Italiano](README.it.md) · Deutsch · [Русский](README.ru.md)

Lies und kommentiere Fachartikel mit Tastenkürzeln im Vim-Stil und schreibe im Editor
für formatierte Zotero-Notizen weiter. Kompatibel mit **Zotero 7–10** unter macOS, Linux und Windows.

Auf der [offiziellen Website von Zotero Vim Plus](https://zorrostardust.github.io/zotero-vim-plus/de/) kannst du die Demo ansehen, das Add-on herunterladen und die Anleitungen in neun Sprachen lesen.

## Installation

Lade `zoetero-vim-plus.xpi` herunter. Öffne in Zotero über das Menü **Extras** die Add-on-Verwaltung.
Wähle im Zahnradmenü die Installation aus einer Datei, wähle die XPI-Datei aus und
starte Zotero neu, wenn du dazu aufgefordert wirst.

Öffne ein PDF und klicke in die Seite. Scrolle mit `j` / `k` oder drücke
`Space` und dann `/`, um Tastenkürzel nachzuschlagen.
Die [Anleitung für Anmerkungen](docs/de/README.md#annotate-pdfs) zeigt dir,
wie du deine erste Hervorhebung erstellst.
