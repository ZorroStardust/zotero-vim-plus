de notas con formato de Zotero. Compatible con **Zotero 7–10** en macOS, Linux y Windows.

## Instalación

Descarga `zoetero-vim-plus.xpi`. En Zotero, abre **Herramientas → Complementos**,
pulsa el icono de engranaje y elige la opción de instalar desde un archivo.
Selecciona el XPI y reinicia Zotero si se te solicita.

Abre un PDF y haz clic en la página. Usa `j` / `k` para desplazarte y pulsa
`Space` y luego `/` para consultar los atajos. Para hacer tu primer resaltado,
sigue la [guía de anotaciones](docs/es-ES/README.md#annotate-pdfs).
