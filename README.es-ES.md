Lee y anota artículos con teclas al estilo de Vim y sigue escribiendo en el editor
de notas de Zotero. Compatible con **Zotero 7–10** en macOS, Linux y Windows.

## Instalación

Descarga `zoetero-vim-plus.xpi`. En Zotero, abre **Herramientas → Complementos**,
pulsa el icono de engranaje y elige la opción de instalar desde un archivo.
Selecciona el XPI y reinicia Zotero si se te solicita.

Abre un PDF y haz clic en la página. Usa `j` / `k` para desplazarte. Pulsa
`Espacio` y luego `/` para consultar los atajos disponibles.
