Lisez et annotez des articles, puis modifiez vos notes avec mise en forme dans Zotero
à l’aide de raccourcis inspirés de Vim. Compatible avec **Zotero 7 à 10** sur macOS, Linux et Windows.

Le [site officiel de Zotero Vim Plus](https://zorrostardust.github.io/zotero-vim-plus/fr/) permet de voir la démonstration, de télécharger l’extension et de consulter les guides en neuf langues.

## Installation

Téléchargez `zoetero-vim-plus.xpi`. Dans Zotero, ouvrez le gestionnaire d’extensions depuis le menu **Outils**,
cliquez sur la roue dentée et choisissez l’installation depuis un fichier. Sélectionnez le XPI,
puis redémarrez Zotero si vous y êtes invité.

Ouvrez un PDF et cliquez dans la page. Utilisez `j` / `k` pour défiler, ou appuyez
sur `Space`, puis sur `/` pour consulter les raccourcis. Pour réaliser votre premier surlignage,
suivez le [guide des annotations](docs/fr/README.md#annotate-pdfs).
