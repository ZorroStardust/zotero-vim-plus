Lisez et annotez des articles, puis modifiez vos notes dans Zotero à l’aide de raccourcis inspirés de Vim. Compatible avec Zotero 7 à 10 sur macOS, Linux et Windows.

[Télécharger le XPI](https://github.com/ZorroStardust/zotero-vim-plus/releases/latest/download/zoetero-vim-plus.xpi) ·
[Guide utilisateur](docs/fr/README.md)

[![Démonstration sans son](BriefDemoVideo.gif)](BriefDemoVideo.gif)

Cliquez dans la page du PDF et utilisez `j` / `k` pour défiler. Appuyez sur `Space /` pour consulter les raccourcis.
