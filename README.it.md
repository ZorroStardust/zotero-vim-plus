## Installazione

Scarica `zoetero-vim-plus.xpi`. In Zotero, apri la gestione dei componenti aggiuntivi dal menu **Strumenti**,
fai clic sull’icona dell’ingranaggio e scegli di installare da un file. Seleziona il file XPI
e riavvia Zotero se richiesto.

Apri un PDF e fai clic nella pagina. Usa `j` / `k` per scorrere, oppure premi
`Space` e poi `/` per consultare le scorciatoie. Per evidenziare il primo brano,
segui la [guida alle annotazioni](docs/it/README.md#annotate-pdfs).
