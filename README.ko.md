## 설치

`zoetero-vim-plus.xpi`를 내려받습니다. Zotero에서 **도구 → 플러그인**을 열고 톱니바퀴 메뉴에서
파일로 설치하는 항목을 선택합니다. XPI 파일을 선택한 뒤 재시작 안내가 나오면 Zotero를 다시 시작하세요.

PDF를 열고 페이지를 클릭한 뒤 `j` / `k`로 스크롤하세요. `Space`를 누른 다음 `/`를 누르면
단축키를 확인할 수 있습니다. 처음으로 텍스트를 강조하려면 [주석 가이드](docs/ko/README.md#annotate-pdfs)를 따라 해 보세요.

## 감사의 말과 라이선스

Zotero Vim Plus는 Alex Fink의 [zotero-vim](https://codeberg.org/finktank/zotero-vim)를 포크한 프로젝트입니다.
[Zotero Neo](https://github.com/zhongyangchuwu/Zotero-Neo)는 Vim Plus를 바탕으로 개발되었으며, 일부 기능은 이후 Vim Plus에도 도입되었습니다.
두 프로젝트와 기여자 여러분께 감사드립니다.
