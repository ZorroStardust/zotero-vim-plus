# Zotero Vim Plus

Read and annotate papers with Vim-style keys, then keep typing in Zotero's rich-text
note editor. Supports **Zotero 7–10** on macOS, Linux, and Windows.

## Installation

Download `zoetero-vim-plus.xpi`. In Zotero, open **Tools → Plugins**, click the gear,
and choose **Install Plugin From File…**. Select the XPI and restart if prompted.

Open a PDF and click the page. Try `j` / `k` to scroll, or press `Space` then `/`
to look up shortcuts. To make your first highlight, follow the
[annotation walkthrough](docs/en/annotate-pdfs.md).
