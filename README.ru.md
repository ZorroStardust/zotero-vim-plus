## Установка

Скачайте `zoetero-vim-plus.xpi`. В Zotero откройте менеджер дополнений через меню **Инструменты**,
нажмите на шестерёнку и выберите установку из файла. Укажите файл XPI и перезапустите Zotero,
если появится запрос.

Откройте PDF и щёлкните по странице. Прокручивайте клавишами `j` / `k`. Чтобы посмотреть
сочетания клавиш, нажмите `Space`, затем `/`. Для первого выделения текста воспользуйтесь
[руководством по аннотациям](docs/ru/README.md#annotate-pdfs).
