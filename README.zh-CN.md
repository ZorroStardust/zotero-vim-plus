# Zotero Vim Plus

> **语言：** [English](README.md) · [Español](README.es-ES.md) · [中文](README.zh-CN.md)

> 原始仓库：https://codeberg.org/finktank/zotero-vim
>
> 本仓库是从原始 Zotero Vim 项目复刻（fork）而来。

为 Zotero 7–10 PDF 阅读器和笔记编辑器提供 Vim 风格按键绑定。
无需鼠标即可导航、标注、搜索和编辑富文本笔记。

由 Claude Sonnet 4.5 以 vibe coding 方式编写。

## 功能

- **普通模式** — 滚动、翻页、在标注之间跳转、复制标注文本、删除标注、
  重定位视口（zt/zz/zb），以及放大时水平平移（`Shift+h`/`Shift+l`）
- **光标模式** — 像浏览器 Vim 插件一样移动文本光标，不选中文本
  （`hjkl`、`w/W`、`b/B`、`0/$`，以及 `2w` 等计数前缀）
- **可视模式** — 按行、字符、单词、句子或段落构建文本选择；创建彩色高亮或
  笔记；将选区或整个段落复制到剪贴板
- **插入模式** — 将所有按键暂时透传给 Zotero（在表单字段中输入时很有用）；
  选中标注时也会聚焦标注注释字段
- **笔记 Vim 编辑器** — 在笔记标签页、文献库右侧条目面板和阅读器笔记侧栏中，
  支持普通、插入、字符可视和行可视模式；提供精确定位、配对跳转、文本搜索、
  文本对象、编辑操作符、待输入命令提示和紧凑绝对行号
- **阅读器与主窗口动作可重映射** — 可在偏好设置面板重新绑定；笔记编辑命令
  目前使用内置的 Vim 按键
- **无快捷键冲突** — vim 消费的按键会在 Zotero 阅读器的按键处理之前被拦截，
  因此 `l`（下一页）不会触发内置的朗读功能，`h`/`s`/`Ctrl+F` 也不会切换
  抓手工具 / 指针工具 / 查找栏
- **文本后处理** — 所有复制操作都会规范化 Unicode 连字（`ﬁ` → `fi` 等）
  并将 PDF 换行折叠为空格
- **快照与 EPUB 支持** — 滚动、搜索（`/` + `n`/`N`）、`gg`/`G`
  （顶部/底部）和 `zt`/`zz`/`zb` 在网页快照和 EPUB 中同样可用
  （快照没有页面，因此 `h`/`l` 会显示提示）。阅读器可视模式、光标模式
  和标注命令仍为 PDF 专属；笔记具有独立的可视模式
- **标记（Marks）** — 类 Vim 位置标记（`m<x>` 设置、`` `<x> `` 瞬移跳转、
  `dm<x>`/`dM` 删除、`<space>m` 浏览浮层），字符可用 `a`–`z` 或 `0`–`9`
  （sioyek 风格数字标签）；可选持久化到父条目的 Extra 字段，重启后保留并同步

## 系统要求

- Zotero 7–10（插件使用 Zotero 7+ 的 bootstrap API）
- macOS、Linux 或 Windows

## 安装

1. 从[最新发布页面](https://github.com/ZorroStardust/zotero-vim-plus/releases/latest)下载 `zoetero-vim-plus.xpi`（或自行构建——见下文）。
2. 打开 Zotero。
3. 进入 **工具 → 插件**。
4. 点击插件窗口右上角的**齿轮图标（⚙）**。
5. 选择**从文件安装插件…**并选中 `zoetero-vim-plus.xpi`。
6. 按提示重启 Zotero。

要更新，请用新的 `.xpi` 重复同样的步骤。Zotero 会自动替换旧版本。

## 从源码构建

```bash
git clone https://github.com/ZorroStardust/zotero-vim-plus.git
cd zotero-vim-plus
./build.sh
```

`build.sh` 将插件源码打包为 `zoetero-vim-plus.xpi`。无需构建工具或包管理器——
只需要 `zip`（macOS 和大多数 Linux 发行版默认自带）。如果 `node` 可用，
该脚本还会检查 JS 语法、插件清单、按键绑定表同步，并运行回归检查。
Node.js 不是插件运行时依赖。

```
zotero-vim-plus/
├── manifest.json          插件清单（ID、版本、Zotero 版本范围）
├── bootstrap.js           生命周期钩子（启动/关闭/窗口事件）
├── build.sh               构建 zoetero-vim-plus.xpi（含完整性检查）
├── content/
│   ├── zoteroVim.js       核心：模式、按键处理、动作分发器
│   ├── zoteroVimReader.js 阅读器侧方法（目录、可视/光标、标注）
│   ├── zoteroVimMain.js   主窗口方法（笔记编辑器、选择器、笔记布局）
│   ├── preferences.xhtml  偏好设置面板 UI（XUL/HTML 混合）
│   └── prefs.js           偏好设置面板 JS（读写 Firefox 偏好）
├── tools/
│   └── check-sync.js      校验按键绑定表保持同步
└── icons/
    ├── icon-64x64.png     插件图标（偏好设置面板、清单）
    ├── icon-128x128.png   插件图标（清单）
    ├── zotero vim plus.svg 标志的矢量源文件
    ├── vim.svg            旧版图标（为兼容保留）
    ├── vim-48.png
    └── vim-96.png
```

## 模式

插件在四种模式下工作，显示在 PDF 阅读器右下角的小浮层中：

| 模式 | 指示器 | 用途 |
|------|-----------|---------|
| **普通模式** | *(隐藏)* | 默认——导航和标注命令 |
| **光标模式** | `-- CURSOR --` | 无文本选择的光标导航 |
| **可视模式** | `-- VISUAL --` | 文本选择与标注创建 |
| **插入模式** | `-- INSERT --` | 透传——所有按键都交给 Zotero |

模式转换：

```
Normal ──c──▶ Cursor ──Escape────▶ Normal
Normal ──v──▶ Visual ──v/Escape──▶ Normal
Normal ──i──▶ Insert ──Escape────▶ Normal
Cursor ──v──▶ Visual ──v/Escape──▶ Normal
```

## 默认按键绑定

### 普通模式

#### 滚动

| 按键 | 动作 |
|-----|--------|
| `j` | 向下滚动 |
| `k` | 向上滚动 |
| `Shift+h` (`H`) | 向左滚动 |
| `Shift+l` (`L`) | 向右滚动 |
| `Ctrl+d` | 向下半页 |
| `Ctrl+u` | 向上半页 |
| `Ctrl+f` | 向下整页 |
| `Ctrl+b` | 向上整页 |
| `Ctrl+o` | 沿 Zotero 阅读位置历史后退 |
| `Ctrl+i` | 沿 Zotero 阅读位置历史前进 |

计数前缀会成倍增加步长——`3j` 滚动三步，`2ctrl+f` 滚动两个整页，
以此类推。

这里使用的是 Zotero 每个阅读视图自身的会话历史。`gg`/`G`、目录、mark、链接和
标注等明显跳转会写入当前分栏的历史；日常 `hjkl` 移动不会污染历史。它与命名
mark 相互独立，也支持计数前缀（如 `3ctrl+o`）。

#### 页面导航

| 按键 | 动作 |
|-----|--------|
| `h` | 上一页 |
| `l` | 下一页 |
| `gg` | 第一页 |
| `G` | 最后一页 |
| `Shift+J` (`J`) | 切换到上一个打开的标签页 |
| `Shift+K` (`K`) | 切换到下一个打开的标签页 |
| `<space>bj` | 打开标签选择器（基于提示字母跳转到打开的标签页） |
| `<space>n` | 打开笔记布局浮层（左侧：笔记标题列表，右侧：笔记预览） |

计数前缀会重复翻页（`3l` = 向前三页），带计数的 `gg`/`G` 会跳转到该页码
（`5G` / `5gg` = 第 5 页）。

> **注意：** Zotero 内置的朗读功能也会监听 `l`/`r` 键。插件会拦截 Zotero
> 阅读器对 vim 所消费按键的转发，因此 `l`（下一页）永远不会触发朗读。
> 要使用朗读，请按 `r`（vim 默认未绑定）或点击朗读工具栏按钮。

#### 模糊选择器

| 按键 | 动作 |
|-----|--------|
| `<space>ff` | 对当前库中的所有条目打开模糊选择器 |
| `<space>fb` | 对当前分类中的条目打开模糊选择器 |
| `<space>bj` | 打开标签选择器（见下文） |

选择器会在屏幕中央打开一个搜索框。开始输入即可筛选条目（顺序模糊匹配——
每个字符必须按顺序出现）。然后：

| 按键 | 动作 |
|-----|--------|
| `↑` / `↓`（或 `Ctrl+n` / `Ctrl+p`、`Ctrl+j` / `Ctrl+k`） | 上 / 下移动选择 |
| `Enter` | 在条目列表中选择该条目 / 跳转到所选标签页 |
| `Ctrl+o` | 打开所选条目的 PDF（仅条目选择器） |
| `y` | 将所选条目的完整引文复制到剪贴板 |
| `yy` | 将所选条目的 citekey 复制到剪贴板 |
| `Escape` | 关闭选择器 |

**标签选择器**（`<space>bj`）对当前打开的标签页使用相同的界面，并额外提供
**提示字母**：每个标签页显示一个字母标签，输入其字母即可直接选择该标签页
（根据标签页数量使用单字母或双字母提示）。`y`/`yy` 复制在标签选择器中不可用。

#### 笔记布局浮层

左侧显示笔记条目（仅标题），分为当前条目笔记和全部笔记两组。
右侧显示当前选中笔记的预览内容。如果当前标签页是 PDF 阅读器，
从该浮层打开笔记时会优先使用 Zotero 的右侧笔记编辑器，以便并排阅读和编辑。

| 按键 | 动作 |
|-----|--------|
| `j` / `k` | 笔记焦点下 / 上移 |
| `Ctrl+d` / `Ctrl+u` | 在笔记列表中快速下 / 上移 |
| `Ctrl+j` / `Ctrl+k` | 在左侧列表的当前条目笔记与全部笔记分区之间切换 |
| `Ctrl+l` | 将焦点移到右侧预览面板 |
| `Ctrl+h` | 将焦点移回左侧笔记列表 |
| `n` | 在所选笔记的父条目下创建新子笔记，并在右侧笔记编辑器中打开 |
| `Shift+N` | 在当前选中条目下创建新子笔记，并在新笔记标签页中打开 |
| `gg` / `G` | 跳到浮层中的第一个 / 最后一个笔记 |
| 提示字母 | 通过提示标签快速聚焦（单键或双键） |
| `Enter` | 在右侧笔记编辑器中打开所选笔记（优先阅读器标签页） |
| `Shift+Enter` | 在新笔记标签页中打开所选笔记 |
| `Escape` | 关闭笔记布局浮层 |

#### 目录浏览

| 按键 | 动作 |
|-----|--------|
| `<space>e` | 切换自定义目录浏览浮层 |
| `j` / `k` | 目录选择下 / 上移 |
| `Ctrl+d` / `Ctrl+u` | 快速下 / 上移 |
| `l` | 展开所选目录节点 |
| `h` | 折叠所选目录节点 |
| `R` / `M` | 全部展开 / 全部折叠目录节点 |
| `gg` / `G` | 跳到顶部 / 底部目录条目 |
| 提示字母 | 选择提示的目录条目而不跳转 |
| `Enter` | 跳转到所选目录条目并返回普通模式 |
| `Escape` | 关闭目录浏览 |

目录浏览打开时会尝试预选离当前阅读位置最近的目录条目；如果 PDF 元数据
无法可靠映射，则回退到第一个可见目录条目。每个可见条目也会显示提示标签。
条目数量少时提示为单字符，否则扩展为双字符提示。输入提示只改变当前选择；
仍需按 `Enter` 跳转。

#### 阅读器分栏视图

| 按键 | 动作 |
|-----|--------|
| `<space>-` | 切换水平分栏（上/下） |
| `<space>\|` | 切换垂直分栏（左/右） |
| `Ctrl+h` | 从右侧笔记编辑器返回活动阅读器面板；否则聚焦左侧分栏面板 |
| `Ctrl+j` | 聚焦下方分栏面板（垂直分栏中则切换面板） |
| `Ctrl+k` | 聚焦上方分栏面板（垂直分栏中则切换面板） |
| `Ctrl+l` | 垂直分栏中，先移动到右侧阅读器面板，再到右侧笔记编辑器；否则聚焦右侧分栏面板 |

#### 标记（Marks）

类 Vim 的位置标记，用于快速跳转。`m<x>` 在当前视口位置设置标记，
`` `<x> `` 跳回该位置。标记字符可用 `a`–`z` 或 `0`–`9`（sioyek 风格数字标签）。

| 按键 | 动作 |
|-----|--------|
| `m<x>` | 在当前位置设置标记（如 `ma`、`m1`） |
| `` `<x> `` | 跳转到标记 —— 瞬移翻页，精确还原打标记时的画面（如 `` `a ``、`` `1 ``） |
| `dm<x>` | 删除标记（如 `dma`） |
| `dM` | 删除全部标记 |
| `<space>m` | 切换标记浏览浮层（输入标记字符直接跳转；`j`/`k` 移动、`Enter` 跳转、`d` 删除、`x` 删除全部） |

说明：

- 标记前缀后的数字是标记字符而非计数 —— `4j` 仍然滚动四步，但 `` `1 ``
  跳转到标记 1。
- 标记记录的是**视口中央**的位置：打标记时屏幕中央的内容，跳转回来后仍在
  屏幕中央 —— 即使是在页面中部也精确还原。
- 如果选中了标注（通过 `[`/`]`），标记也会绑定到该标注，跳转后 `[`/`]`、
  `zy`、`y` 等后续命令照常可用。`[`/`]` 跳转注释不受影响。
- 启用 **持久化标记**（偏好设置 → 标记）后，全部标记会保存为**父条目 Extra
  字段**中的 `zv-marks-<附件key>:` 行（随 Zotero 同步——Zotero 9 的附件没有
  Extra 字段，因此存在父条目上；一个条目下的多个 PDF 各自独立成行），失败
  时回退到本机 pref。状态栏会显示实际使用的后端（`· saved (extra)` /
  `· saved (local)`）。旧注释标签方案的标记会自动迁移。
- 未启用持久化时设置的标记仅在当前阅读器会话内有效。

#### 笔记 Vim 编辑器

当 Zotero 笔记编辑器获得焦点时，插件提供类 Vim 导航、搜索和富文本编辑。
支持文献库右侧条目面板、阅读器笔记侧栏和独立笔记标签页。笔记 Vim 与
PDF 阅读器模式独立，默认开启，可在 **设置 → Zotero Vim Plus → 模式** 中关闭。

快速上手：点击笔记正文，按 `Escape`，确认状态显示 **NOTE NORMAL**。
用 `hjkl` 移动，按 `i` 输入，按 `Escape` 回到普通模式。试试 `12G` 跳到第 12 行、
`f,` 定位逗号、`/` 搜索、`viw` 选中一个词，或 `ci"` 修改引号内的文字。
`f`、`d`、`ci` 等等待后续按键的命令会在底部显示提示。

| 按键 | 动作 |
|-----|--------|
| `i` | 进入笔记插入模式（透传输入） |
| `a` / `A` / `I` | 在下一字符 / 行尾 / 第一个非空白字符进入插入模式 |
| `o` / `O` | 在下方 / 上方打开新行并进入插入模式 |
| `Escape` | 返回笔记普通模式 |
| `h` / `l` 或 `←` / `→` | 光标左 / 右移 |
| `j` / `k` 或 `↓` / `↑` | 光标下 / 上移行 |
| `w` / `e` / `b` | 按单词移动（前进到词首 / 词尾 / 后退） |
| `W` / `E` / `B` | 大单词变体 |
| `0` / `^` / `$` | 移动到行首 / 第一个非空白字符 / 行尾 |
| `gg` | 跳到第一行 |
| `G` | 跳到最后一行 |
| `3j`（示例） | 动作的计数前缀（重复 3 次） |
| `3G` / `12gg` | 计数前缀跳转到特定行号 |
| `f{字符}` / `F{字符}` | 在当前逻辑行向行尾 / 行首查找字符 |
| `t{字符}` / `T{字符}` | 移动到向行尾 / 行首找到的字符之前 / 之后 |
| `;` / `,` | 同向 / 反向重复上一次字符定位 |
| `%` | 在匹配的 `()` / `[]` / `{}` 之间跳转；先查找本行光标处或之后的括号 |
| `50%`（示例） | 跳到文档 50% 位置对应的行 |
| `/` / `?` | 向文末 / 文首搜索笔记；Enter 确认，Escape 取消 |
| `n` / `N` | 沿上次搜索方向 / 反方向跳到匹配项，可循环 |
| `*` / `#` | 向文末 / 文首搜索光标下的完整词 |
| `v` / `V` | 进入字符可视 / 逻辑行可视模式 |
| `gv` | 笔记正文未变化时恢复上次可视选区 |
| `x` | 删除光标处的字符 |
| `dd` | 删除当前行 |
| `yy` | 将当前行复制到剪贴板 |
| `dw` / `de` / `db` / `d$` | 按动作删除（单词 / 词尾 / 向后单词 / 到行尾） |
| `yw` / `ye` / `yb` / `y$` | 按动作复制 |
| `cw` / `ce` / `c$` | 按动作修改（删除范围并进入插入模式） |
| `d{文本对象}` / `y{文本对象}` / `c{文本对象}` | 删除 / 复制 / 修改文本对象（见下文） |
| `p` / `P` | 在光标后 / 前粘贴字符文本，或在当前行下方 / 上方粘贴整行 |
| `u` / `Ctrl+r` | 撤销 / 重做桥接 |
| `<space>...` | 主窗口 leader 绑定在笔记普通模式中可用（例如 `<space>n`、`<space>ff`） |
| `Shift+J` / `Shift+K` | 普通模式切换到上一个 / 下一个标签页；插入模式输入 `J` / `K` |

`dd`、`yy` 和 `x` 支持计数前缀（例如 `3dd`、`5yy`、`4x`）。操作符 + 动作
组合也支持计数（例如 `3dw`、`2y$`）。操作符前后的计数相乘：`2d3w` 删除六个词。
`1G` 跳到第一行，单独 `G` 跳到最后一行。`p` / `P` 支持 `3p` 等计数，使用
内部笔记复制缓冲区；复制、删除和修改操作（包括 `x`）会更新它。

实体方向键只在笔记普通/可视模式中作为 Vim 移动键；插入模式中方向键及其修饰键
完全交给编辑器。若编辑器命令菜单已打开（包括 Better Notes 的 `/` 菜单），第一次
按 `Escape` 只关闭菜单并停留在插入模式；再次按 `Escape` 才返回普通模式。
明确关闭 Better Notes 菜单后，删除字符重新退回同一个 `/` 时不会再次弹出；主动
输入新的 `/` 或 `Ctrl+/` 会重新允许菜单打开。

精确定位可与操作符、计数组合：`2fa` 找到第二个 `a`，`dt)` 删除到 `)` 之前，
`df)` 包含 `)`，`d%` 包含配对括号的两端。`;` / `,` 不改变最初记住的定位方向。
定位失败不改变正文或光标。字符定位仅限当前逻辑行；配对跳转可跨段落，
会跳过转义分隔符和单行引号内容，但不是语言语法解析器。

待输入命令会在笔记底部显示紧凑、不可交互的提示。例如 `f` 显示方向并等待字符，
`2d3f` 显示已输入命令及第六次匹配。计数、操作符和文本对象也会提示下一步。
提示使用插件语言设置或 Zotero 语言，目前支持中英文；直到完成或 Escape 才消失，
离开编辑器也会取消。它不移动选区、不进入保存的 HTML 或撤销历史，打印时隐藏。

搜索是区分大小写的**纯文本搜索**，不是 Vim 正则表达式。支持中文等 Unicode 文本、
实时匹配数、下一匹配项高亮预览和首尾循环。在底部搜索栏输入查询，Enter 确认并
返回正文；Escape 或移开焦点会取消并恢复原来的光标或选区。空查询按 Enter
重复上次搜索。`3n` 跳过三个匹配项；`d/查询`、`c?查询` 可与操作符组合。
`*` / `#` 匹配完整词，而非词内片段。搜索栏不属于笔记正文，打印时隐藏。
尚不支持替换、Vim 正则语法或命令行。

可视模式中，移动、计数、字符定位、`%`、搜索和文本对象会扩展选区。
`o` 交换活动端，`y` 复制，`d` / `x` 删除，`c` 删除并进入插入模式。
`v` / `V` 切换选区类型；再次按当前类型键或 Escape 返回普通模式。
可视模式下 `J` / `K` 不切换标签页。尚无矩形/块可视模式；正文变化后，
`gv` 会拒绝恢复旧位置，以免误选。

文本对象可接在 `d` / `y` / `c` 后，也可在可视模式使用：

| 内部 / 包含周围 | 对象 |
|----------------|------|
| `iw` / `aw`、`iW` / `aW` | 词 / 空白分隔的 WORD；包含周围时带相邻空白 |
| `is` / `as` | 句子，识别英文和中文句末标点 |
| `ip` / `ap` | 段落；包含周围时带相邻空段落/空行 |
| `i"` / `a"`、`i'` / `a'`、`` i` `` / `` a` `` | 单行引号内容，跳过转义引号 |
| `i(` / `a(`、`ib` / `ab` | 圆括号 |
| `i[` / `a[`、`i{` / `a{`、`iB` / `aB`、`i<` / `a<` | 方括号 / 花括号 / 尖括号 |
| `it` / `at` | 正文中写出的成对 HTML/XML 标签，不是编辑器的富文本格式标签 |

右括号键也可作为别名（`i)` 等于 `i(`）。计数可选择更外层嵌套对（`2ci(`），
可视模式中重复对象也会向外扩展。可尝试 `ci"` 修改引号内容、`da(` 删除括号段，
或 `viw` 后按 `y` 复制词。富文本段落对象使用编辑器实际的段落、标题和列表项；
纯文本回退使用连续非空行。这不是对 Vim 可配置句子/段落规则的完整模拟，
也不提供语法感知的标签解析。

富文本中的行指逻辑段落或显式换行，不是自动折行后的屏幕行。`o` / `O`
在下方 / 上方插入干净空行，不拆分原行尾部文字；简单列表中创建同级列表项。
原生编辑器事务保留剩余内容格式，并接入 Zotero 的撤销和保存流程。
插入模式下 `Ctrl+Backspace` 透传；`Ctrl+h` / `Ctrl+l` 仍是显式焦点切换快捷键。
普通模式也可用 `<space>bj` 直接选择标签页。

关闭笔记 Vim 后恢复原生输入。笔记标签页或侧栏编辑时，主窗口导航快捷键
（包括用于返回父分类的 Backspace）不会抢占输入。

活动笔记默认显示绝对行号，并高亮当前行。编号与 `12G`、`12gg`、`j` / `k`
使用相同逻辑行：空段落和显式换行计数，自动折行不增加编号。行号复用紧凑左边距；
标题有 H1/H2 等级标记时，在标记下方使用扁平小数字，不额外占一列，仅在需要时
为这些标题留少量垂直间距。表格单元格使用局部小边栏，编号仍按文档全局顺序。
行号仅为界面，不进入笔记保存内容、复制正文、导出或撤销历史，打印时隐藏。
在 **设置 → Zotero Vim Plus → 模式 → 在笔记编辑器中显示绝对行号** 中切换，
无需重启。行号需要笔记 Vim 和 Zotero 原生编辑器视图；旧版回退编辑器没有行号，
但其余编辑操作仍可使用。

**macOS 输入修复（v1.10.0）：** 普通模式移动不再输入命令字母，进入插入模式
也不会将 `i` / `a` / `o` 写入笔记。
[issue #6 报告者已确认笔记标签页和侧栏笔记均已修复](https://github.com/ZorroStardust/zotero-vim-plus/issues/6#issuecomment-5947724456)。
关闭笔记 Vim 后 Backspace 和普通输入保持原生行为，不再触发分类导航。

这是 Zotero 富文本编辑器上的实用类 Vim 操作层，并非完整 Vim 引擎。
尚未实现 `:` 命令行、替换、Vim 配置文件、命名寄存器体系、块可视模式或笔记
命令重映射。内部复制缓冲区不是完整的 Vim 寄存器实现。

## 标注工作流

### 从零创建高亮

1. 按 `v` 进入可视模式。
2. 按目标句首显示的提示字母（或按 `j`/`k` 从当前位置开始）。
3. 用 `j`/`k`/`w`/`b`/`)`/`}`/`h`/`l` 扩展选择。
4. 如需修剪起点而不是扩展终点，用 `o` 跳到选择的另一端。
5. 按 `zy`/`zr`/`zg`/`zb`/`zp` 创建彩色高亮，或按 `za` 添加笔记。

### 导航与编辑已有标注

1. 按 `]` / `[` 移动到下一个 / 上一个标注。标注会在 PDF 阅读器中高亮，
   侧边栏会滚动到其卡片。
2. 按 `y` 复制高亮文本，`yy` 复制注释。
3. 按 `i`（或 `Enter`）打开注释字段并输入笔记。按 `Escape` 返回普通模式。
4. 按 `dd` 删除标注。

## 自定义按键绑定

打开 **编辑 → 偏好设置**（macOS：**Zotero → 设置**），
进入 **Zotero Vim** 标签页。

- **按键绑定**表中的每一行都将一个 *模式 + 键序列* 映射到一个 *动作*。
- 点击键序列单元格可直接编辑。
- 按键区分大小写（`g` 与 `G` 不同）。Ctrl 用 `ctrl+` 前缀（macOS 上为 Cmd）；
  Shift 字母直接写成大写，不使用 `shift+`。
- 支持 `gg`、`zy`、`yy` 等多键序列。
- 点击 **+ 添加绑定** 添加新行；点击 **×** 后再点 **应用绑定** 才会真正解绑，
  默认按键也可以解绑。
- 点击 **应用绑定** 保存按键绑定更改。
- 重复的“模式 + 按键”和无效按键会在行内提示，且不会覆盖上一次可用配置。
- 高亮颜色、模式、标记与滚动设置在更改时自动保存。
- 可视、光标、插入和笔记编辑器 Vim 模式都可以独立开启或关闭；笔记编辑命令仍是
  固定键位，不在这个绑定表中重映射。
- 点击 **重置为默认值** 将所有绑定恢复为默认值。

偏好设置面板使用稳定的面板 id 注册，因此即使重启后也会直接定位到上次
停留的设置区块；下拉框采用 Zotero 原生的 `menulist` 控件，确保每次打开
都稳定可用。面板初始化异常会以 `[prefs]` 前缀记录到配置文件目录下的
`zv-startup.log`。

## 架构说明

这些说明面向贡献者或任何调试插件的人。

### 三层 iframe 栈

Zotero 的 PDF 阅读器渲染在嵌套的 iframe 中：

```
Zotero chrome window
  └─ reader.html          (reader._iframeWindow)
       └─ PDF.js iframe   (reader._internalReader._primaryView._iframeWindow)
```

按键事件在最内层（PDF.js）通过 `pdfWin.addEventListener` 注册的
`capture: true` 的 `keydown` 监听器捕获。

### Cross-Compartment 安全

`reader._internalReader` 和 PDF.js 查看器对象位于与 Zotero chrome 上下文
不同的 JavaScript 安全域（compartment）。任何跨此边界作为参数传递的
JavaScript 对象或数组都必须先克隆：

```js
Components.utils.cloneInto(value, targetWindow)
```

基本类型值（数字、字符串、布尔值）可以自由跨域。忘记 `cloneInto` 会产生
`"Permission denied to access property"` 错误，这类错误容易被忽略，
因为它们常常被捕获并静默吞掉。

### Zotero 内置快捷键冲突（朗读 Read Aloud）

Zotero 阅读器 React 应用在 `l`/`r` 键上启动朗读，并从其 `KeyboardManager`
在 `h`/`s` 上切换抓手工具 / 指针工具。在 PDF.js iframe 内按下的键通过
**直接 JS 调用**到达它——`view._onKeyDown(event)`（在阅读器的
`pdf-view.js` 中）——而不是通过 DOM 事件传播。这意味着：

- PDF.js iframe 内的 `preventDefault()` / `stopPropagation()` 无法阻止它：
  Zotero 的捕获监听器与插件的监听器运行在*同一*窗口上，而转发是普通函数
  调用，不是事件分发。
- 原生 keydown 事件永远不会跨 iframe 边界进入 reader.html，因此那里的
  文档级拦截器永远看不到 PDF 按键。

因此插件会修补转发回调本身：

- `_patchReaderKeyForwarding()` 用包装器替换 PdfView 实例
  （`_internalReader._primaryView` / `_secondaryView`）上的 `_onKeyDown`，
  当 `_readerConsumesKey()` 表示 vim 将处理该键时丢弃该事件（当前模式的
  精确绑定或前缀）。插入模式除 Escape 外全部透传。
- 包装器通过 `Cu.unwrap` + `Cu.exportFunction` 跨 chrome/content 边界
  （裸的 chrome 函数会被 content 域拒绝）。
- 无论 vim 在何处消费按键，`_onKeyDown` 都额外使用
  `stopImmediatePropagation()`（而非 `stopPropagation()`），因此当插件的
  监听器先注册时，Zotero 的同窗口捕获监听器会被跳过。

该修补由 800 ms 的视图同步计时器重新应用，因此可跨视图重建、分栏视图
和恢复会话存活。如果 Zotero 更改阅读器的转发内部实现，请重新验证
`view._onKeyDown` 和 `KeyboardManager` 快捷键表（keyboard-manager.js）。

### 标注导航

`reader._internalReader.setSelectedAnnotations(Cu.cloneInto([key], readerWin))`
是处理所有事情的单次调用——它会滚动 PDF 到标注、显示选中轮廓，
并滚动侧边栏卡片进入视野。**不要**再调用 `currentPageNumber = N` 或
`scrollPageIntoView`；它们会与内部导航竞争并导致跳跃式的翻页。

### 可视模式下的文本选择

PDF.js 将每个可视行渲染为 `.textLayer` 元素中绝对定位的 `<span>`
（每页一个 `.textLayer`）。`Selection.modify('extend', 'line')` 等浏览器
API 在此上下文中不可靠。

插件实现了自己的按行扩展（`_extendByLine`），使用
`document.caretPositionFromPoint` 和回退的 span 几何扫描。句子和段落扩展
（`_extendBySentence`、`_extendByParagraph`）使用
`document.querySelectorAll('.textLayer span')` 扫描*所有页面*的
`.textLayer span` 元素——**不是** `document.querySelector('.textLayer')`，
后者只返回第一页。

选择通过 `state.visualCursor = { textNode, offset }` 作为锚点跟踪，
以便 PDF.js 偶尔清除浏览器选择时 `sel.addRange()` 能重建正确的范围。

### 文本后处理（yank 操作）

所有剪贴板操作都会将原始的 `sel.toString()` 或 `annotationText` 经过：

1. `text.normalize('NFKC')` — 分解 Unicode 连字（`ﬁ` → `fi` 等）
2. `text.replace(/\n/g, ' ')` — 将 PDF 换行折叠为空格
3. `text.replace(/ {2,}/g, ' ').trim()` — 规范化空白

### 标注注释字段

标注注释是一个 `contenteditable` div，带有 `aria-label="Annotation comment"`，
位于由 `[data-sidebar-annotation-id="${key}"]` 标识的侧边栏卡片内。
只使用 `.focus()` 聚焦——从 chrome 上下文调用 `.click()` 会创建特权
`MouseEvent`，content 代码无法读取，导致安全包装器错误。
