# Install Zotero Vim Plus and try your first shortcuts

[Documentation](../README.md) · [简体中文](../zh-CN/getting-started.md)

Zotero Vim Plus supports Zotero 7–10 on macOS, Linux, and Windows.

## Install

1. Download `zoetero-vim-plus.xpi` from the [the download page](https://github.com/ZorroStardust/zotero-vim-plus/releases/latest).
2. In Zotero, open **Tools → Plugins**. Click the gear icon and choose
   **Install Plugin From File…**.
3. Select the downloaded XPI and restart Zotero if prompted. Check that
   **Zotero Vim Plus** is enabled in the Plugins window.

To update manually, install the new XPI from the same menu.

To change the plugin language, open **Zotero Vim Plus → General → Language** in Zotero’s settings.

## Try it on a PDF

1. Open a PDF in Zotero and click the page to focus it.
2. Press `j` to scroll down and `k` to scroll up. Press `/` to search the PDF,
   type a word, and press `Enter`. Use `n` / `N` to move through matches and
   `Esc` to close the search.
3. Press and release `Space`, then press `/` to open the searchable shortcut
   reference. Type a key or an action name, then press `Esc` to return to the PDF.

Next, [make a highlight](annotate-pdfs.md#make-a-highlight) or
[edit a note](edit-notes.md). To search the Zotero library, see
[Find and organize papers](manage-library.md). If the keys do something unexpected, check
[which area has focus](troubleshooting.md#keys-do-nothing-or-control-the-wrong-area).
