# Guida a Zotero Vim Plus

[Lingue](../README.md) · [Progetto](https://github.com/ZorroStardust/zotero-vim-plus/blob/main/README.it.md)

## Installazione e lingua

Scarica il [file XPI](https://github.com/ZorroStardust/zotero-vim-plus/releases/latest/download/zoetero-vim-plus.xpi). In Zotero, apri la gestione dei componenti aggiuntivi dal menu **Strumenti** e installa il file tramite il menu con l’ingranaggio. Il componente supporta Zotero 7–10. Nelle impostazioni di Zotero scegli l’italiano in **Zotero Vim Plus → Generali → Lingua**.

<a id="read-pdfs"></a>

## Leggere e navigare i PDF

Fai clic nella pagina. Usa `j` / `k` per scorrere e `h` / `l` per cambiare pagina. Premi `/` per cercare, conferma con `Invio` e passa tra i risultati con `n` / `N`. Usa `Space f h` per cercare nell’indice, `Space f g` per le didascalie di figure e tabelle e `f` per mostrare i suggerimenti sui link e sulle annotazioni visibili. Per cambiare il tema del PDF premi `Space r t`, poi `f` e le lettere del tema.

<a id="annotate-pdfs"></a>

## Selezionare e annotare

Premi `v` e scegli un suggerimento per iniziare la selezione. Con `Shift+V` puoi digitare un testo visibile e scegliere una corrispondenza. Regola la selezione con `h` / `j` / `k` / `l`. L’indicatore mostra il numero di caratteri selezionati. Usa `y` per copiare, `i` per commentare, `zy` per evidenziare in giallo e `zY` per sottolineare. `t` traduce la selezione se Translate for Zotero è configurato. `[a` / `]a` passa all’annotazione precedente o successiva.

<a id="manage-library"></a>

## Cercare e organizzare gli articoli

Cerca nella biblioteca con `Space f f` o nella raccolta corrente con `Space f b`. Nell’elenco degli elementi, usa `s` per aggiungere o rimuovere elementi dalla selezione temporanea. Controllala con `Space s s` prima di modificare i tag con `Space t a` o `Space t r`. Crea un gruppo di lettura con `Space b c` e aprilo con `Space b l`.

<a id="edit-notes"></a>

## Modificare le note di Zotero

Apri il selettore delle note con `Space n`. `Ctrl+k` mostra le note dell’elemento corrente e `Ctrl+j` tutte le note. `Invio` apre la nota e `Shift+Invio` la apre in una scheda separata. `Space r n` mostra o nasconde la barra delle note nel lettore. Nell’editor, `Esc` attiva **NOTE NORMAL**, `i` consente di scrivere e `Esc` torna alla modalità normale.

<a id="shortcuts"></a>

## Consultare le scorciatoie

Usa `Space /` per vedere le assegnazioni attive e `Space p` per aprire le impostazioni. Modifica le assegnazioni in **Scorciatoie** e salvale con **Applica scorciatoie**.

<a id="troubleshooting"></a>

## Risolvere i problemi

Se un tasto non risponde, verifica quale pannello ha il focus e la modalità attiva.
