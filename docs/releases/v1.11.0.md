## v1.11.0 — Spacekeys, shortcut reference and native library search

This release adds shortcut discovery throughout Zotero, native search from the
library's focused pane, and new PDF reading tools. It includes all changes since
v1.10.0.

### Spacekeys and searchable shortcut reference

- Press `Space` to show grouped hints in the bottom-right corner. Continue
  typing to narrow the available chords. Hints follow effective custom bindings
  in the library, reader and note Normal mode.
- Configure the hint delay and leader timeout in Settings. Canceling an
  unfinished Space chord with `j/k` starts smooth scrolling immediately.
- `Space /` opens a centered reference covering reader, library, note and popup
  commands. Related keys share a row in a compact two-column layout; narrow
  windows use one column.
- Search by key, action or mode in English or Chinese. `Ctrl+h/l` cycles
  categories while preserving the query; `Ctrl+j/k` scrolls. Escape closes the
  reference and restores focus and selection.
- The reference reflects remaps and unbindings, shares descriptions with
  Settings, and includes command families such as counts and text objects.

**Shortcut change:** the library's former `Space /` search binding now opens
the shortcut reference. An explicitly saved old default is migrated once;
other custom bindings and explicit unbindings are preserved. The direct
`mainFocusSearch` action remains available for custom bindings.

### Native library search with `/`

- In the collection tree, `/` opens Zotero's native collection filter, ready
  for immediate typing. Filtered `j/k` and `gg/G` navigation skips contextual
  ancestor rows using native matching-row navigation.
- In the item list, `/` focuses the native quick search input. `Ctrl+h/l`
  cycles through **Title, Creator, Year**, **All Fields & Tags**, and
  **Everything**, preserving the query and updating Zotero's menu, placeholder
  and remembered search mode.
- Enter applies the query and returns to the corresponding tree or list.
  Escape clears that search and returns in one press.
- On versions without the native collection filter, a collection picker
  searches collapsed descendants and saved searches, with parent paths.
- Fixed focus detection so an existing collection selection does not override
  actual item-list focus. Native mode menus, IME input and ordinary search
  typing retain input ownership; stale search completions do not restore focus
  after changing tabs or leaving the search.

PDF and note `/` searches continue to use their own search interfaces.

### PDF headings and clearer focus

- `Space fh` searches all PDF outline headings, including collapsed descendants.
  Results show parent paths and page numbers; Enter jumps in the originating
  PDF pane. `/` opens the same search from a focused outline tree.
- `Ctrl+h` moves from a PDF to its open outline and `Ctrl+l` returns to the PDF.
  Escape from heading search restores the original outline selection, expansion
  and scroll when opened from that tree.
- Theme-aware frames identify the focused PDF pane, outline or note editor.
  The active PDF pane also has a small viewport-corner dot. These cues follow
  focus, respect reduced motion and hide while a plugin popup owns input.
- Split initialization focuses the new pane when ready, keeping keyboard
  commands and focus cues synchronized. Later user input cancels a pending
  handoff; background initialization does not retarget commands.
- Fixed leaving a right-pane outline for the left PDF with `Ctrl+h`, and
  reduced padding between adjoining split panes while preserving the divider.

### Translation, dictionary lookup and native two-page reading

- With **Translate for Zotero** installed and configured, Visual-mode `t`
  opens a translation popup for the selection using that plugin's service and
  languages. A single word uses its configured dictionary service when enabled.
  Selected text is sent to that service when the translation key is pressed.
- The popup supports scrolling, copying and dismissal while a request is
  pending. Closing restores the selection in Visual mode; late responses do
  not reopen it. Dictionary details depend on the selected service.
- `Space s` toggles native single/two-page PDF view in the focused pane.
  `Space S` switches odd/even pairing. Returning to single-page view restores
  the previous zoom and scrolling mode; split panes keep independent layouts.

### Reading, editing and input fixes

- `Ctrl+o/i` navigates Zotero's native reading-position history in the active
  PDF pane, including count prefixes.
- Added word-under-caret search with `*` / `#`, sentence/paragraph selection
  motions, inner-word/quote/bracket text objects and `.` to repeat the last
  annotation change. Cursor character finds handle counts and cancellation
  more reliably.
- An optional page-progress display shows the current page, total and
  percentage in the mode indicator.
- Fixed item-picker typing so `y/yy` remain search text; explicit `Ctrl+y`
  and `Ctrl+Shift+y` copy citations and citekeys. A stationary mouse no longer
  overrides keyboard selection while filtering or scrolling results.
- Fixed dismissed Better Notes slash menus reopening during editing or after
  Vim mode changes, and improved native note-popup handling and arrow motions.
- Improved binding validation, custom-key prefix handling and preference
  synchronization across default bindings and localized action descriptions.

### Installation and validation

Download **`zoetero-vim-plus.xpi`**, install it through **Tools → Plugins →
gear menu → Install Plugin From File…**, then restart Zotero. Supported
versions remain **Zotero 7.0–10.***. Automatic-update metadata points to
v1.11.0.

The release build runs syntax, manifest, binding synchronization and regression
checks, including 21 native-library-search cases, 18 shortcut-reference cases
and 13 Spacekeys cases. English and Chinese documentation describes the new
commands and their context-dependent behavior.

## 中文摘要

- **Spacekeys：** 按 Space 后在右下角显示分组按键提示，支持自定义绑定、提示延迟
  和组合键超时；取消待完成组合后按 `j/k` 可立即平滑滚动。
- **快捷键总览：** `Space /` 打开居中的可搜索面板，采用紧凑双列布局并合并相关
  按键；`Ctrl+h/l` 切换分类，`Ctrl+j/k` 滚动，保留搜索词并支持中英文搜索。
- **原生文献库搜索：** 分类树按 `/` 筛选分类，条目列表按 `/` 进入原生快速搜索；
  `Ctrl+h/l` 切换三种条目搜索模式，Enter 保留搜索并返回，Esc 清空并返回。
  分类筛选立即可输入，`j/k` 跳过灰色父级行；旧版使用包含折叠子级的分类选择器。
- **目录搜索与焦点：** `Space fh` 搜索全部 PDF 目录标题；聚焦目录时 `/` 打开
  同一搜索。完善目录、PDF 分栏和笔记间的焦点切换与提示，修复右侧目录无法
  返回左侧 PDF 的问题。
- **翻译与词典：** 配合 Translate for Zotero，在可视模式选中文字后按 `t`
  显示翻译或词典结果，支持滚动、复制及恢复选区；按翻译键后，所选文字会发送
  给该插件配置的服务。
- **双页阅读：** `Space s` 切换单／双页，`Space S` 切换奇偶页配对；分栏独立，
  返回单页时恢复原缩放和滚动方式。
- **阅读与修复：** 新增阅读历史前进／后退、词搜索、句子／段落选择、文本对象、
  重复标注操作及页码进度；修复选择器输入与键鼠焦点争抢、笔记斜杠菜单重复弹出，
  并完善自定义按键校验。
- **升级提示：** 文献库原 `Space /` 搜索入口改为快捷键总览，按焦点搜索改用 `/`。
  自定义绑定及明确解绑会保留，`mainFocusSearch` 仍可手动绑定。支持 Zotero 7–10。
