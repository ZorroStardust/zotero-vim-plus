## v1.12.0 — Better item search and reading-position-aware PDF outlines

### Item picker

- `Space ff` and `Space fb` open the item picker for the current library or
  collection. With an empty query, the picker shows recently added references
  first. Each row starts with the title and shows a citekey when available.
- Search titles, all creators, years, and citekeys. Exact and whole-word matches
  rank ahead of prefixes, substrings, and fuzzy matches. Query terms can match
  different fields in any order. [Issue #9](https://github.com/ZorroStardust/zotero-vim-plus/issues/9)
- Press `Ctrl+h` / `Ctrl+l` to cycle through **Title, Creator, Year**,
  **All Fields & Tags**, and **Everything**. The last mode also searches text
  indexed by Zotero from attachments.
- Press `Ctrl+Shift+h` / `Ctrl+Shift+l` to choose references, any item,
  top-level items, attachments, notes, or annotations. Both sets of options
  are clickable and keep the current query.
- `Ctrl+o` opens the highlighted result. Selecting an annotation opens its
  attachment at that annotation.

### PDF outline

- Heading search (`Space fh` or `/` in the outline tree) starts at the chapter
  you are reading in the originating PDF pane.
- Opening the outline tree reveals that chapter, expands its parent path, and
  scrolls it into view. Destination coordinates distinguish headings on the
  same page when the PDF provides them. [Issue #7](https://github.com/ZorroStardust/zotero-vim-plus/issues/7)

## 中文摘要

- **条目选择器**默认按添加时间显示文献，以标题为主，有引用键时再显示。搜索涵盖
  所有创建者，优先显示精确匹配和完整词。`Ctrl+h/l` 切换搜索范围，
  `Ctrl+Shift+h/l` 独立切换条目类型。两排选项均可点击，切换时保留查询。
- **打开结果**时，`Ctrl+o` 使用选择器中高亮的条目。选择批注会打开附件并定位到该批注。
- **PDF 目录**从当前 PDF 窗格的阅读章节开始。打开目录树时会展开该章节的父级并滚动到位。

Supports Zotero 7–10. [Full changelog](https://github.com/ZorroStardust/zotero-vim-plus/compare/v1.11.0...v1.12.0)
