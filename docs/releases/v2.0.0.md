## v2.0.0 — Keyboard workflows from PDF reading to library organization

[简体中文](#简体中文) · [Project website](https://zorrostardust.github.io/zotero-vim-plus/) · [User guide](https://zorrostardust.github.io/zotero-vim-plus/en/getting-started.html)

Find a passage in a PDF, select and annotate it, then open the right Zotero note without leaving the keyboard. This release also adds temporary library selections, saved reading groups, and a keyboard-driven settings panel.

### Find, select, and annotate PDF text

- **Flash selection.** Press `Shift+V` and type part of a visible word or phrase. Choose a letter hint or press `Enter` for the match closest to the center of the pane. Press `Shift+V` again to move the active end of the selection while keeping its anchor. `Shift+C` places the text cursor at a match.
- **Selection feedback.** The indicator shows the selected character count as you adjust the range and displays shortcuts for copying, commenting, choosing an annotation color, and translating. Translation still uses your configured Translate for Zotero service.
- **Reading order and body text.** Cursor movements, Flash, and keyboard selections follow the PDF's reading order more consistently across columns. Run **Toggle body text only** in the command palette to skip recognized page furniture such as running headers, page numbers, captions, and footnotes.
- **Highlights, underlines, and comments.** Press `z` to see eight color choices. A lowercase second key highlights and an uppercase second key underlines, such as `zy` and `zY` for yellow. The same chords can recolor or restyle a selected highlight or underline. `i` opens the new annotation's comment editor, `y` copies the selected annotation's excerpt or note text, and `yy` copies its comment. `Esc` clears the annotation selection.

### Follow references and jump within a paper

- **On-screen links and annotations.** Press `f` in PDF Normal mode for letter hints on visible links, citations, and annotations. Follow an internal link, select an annotation, or preview a reference or external URL. In a grouped reference preview, use `Ctrl+j` / `Ctrl+k` to move, `Space` to mark entries, and `y` to copy the marked references.
- **Figures, tables, and headings.** Use `Space f g` to find figure and table captions by label, text, or page. When the figure or table can be identified, the jump briefly frames it. The outline docks beside the PDF so you can keep it open while reading.
- **Keyboard controls in Zotero's PDF tools.** In the find box, `Ctrl+j` toggles **Highlight all**, `Ctrl+k` toggles **Match case**, and `Ctrl+l` toggles **Whole words**. Press `Space r t`, then `f` and a hint, to choose a native PDF reading theme.

**Shortcut changes for existing users**

| Previous / next | Target |
| --- | --- |
| `[a` / `]a` | Annotation |
| `[f` / `]f` | Figure |
| `[t` / `]t` | Table |
| `[s` / `]s` | PDF outline heading |
| `[m` / `]m` | Vim mark |

Bare `[` and `]` now start a jump chord. To select a word in PDF Visual mode, use `giw` in place of `iw`. Note editing still uses `viw`. Press `Space /` to check your current bindings.

### Organize papers and open notes

- **Temporary selection.** Press `s` in the item list to add or remove items, `Space s s` to review the selection, and `Space s c` to clear it. The selection survives collection and filter changes within the current window. Use `Space t a` / `Space t r` to add or remove a tag, or `Space c a` to add top-level items to a collection in the same library. When the temporary selection is empty, these operations use Zotero's current selection. Check the target summary before applying changes.
- **Reading groups.** Use `Space b c` to save selected PDFs as a group, `Space b a` to add PDFs to an existing group, and `Space b l` to browse and open them. Groups and their ordering are stored in the local Zotero profile. Removing a group or a PDF from it preserves the original Zotero items and files.
- **Note picker and sidebar.** `Space n` opens the note picker. Use `Ctrl+k` for the current item, `Ctrl+j` for all notes, and `Ctrl+l` / `Ctrl+h` to move between the list and preview. Each scope remembers its selection and scroll position while the picker is open. Use `Space r n` to toggle the reader's notes sidebar from the PDF or from **NOTE NORMAL** inside the sidebar.
- **Item search refinements.** Exact matches and complete words get more consistent priority when a query spans several fields, including titles, creators, years, and citation keys.

### Commands and settings

- **Command palette.** Press `:` in the library or PDF Normal mode, search for an action, and press `Enter` to run it. Use `Space /` to look up assigned keys.
- **Keyboard settings and themes.** `Space p` opens the settings panel. Use `Shift+J` / `Shift+K` to switch tabs and `f` for control hints. Zotero's plugin preferences are also organized into tabs. The **Appearance** tab previews Vim Plus themes, supports a custom palette, and uses consistent colors across the Classic theme's panels and mode indicators.
- **Nine interface languages.** Settings screens and common action names are available in English, Simplified Chinese, Spanish, Japanese, Korean, French, Italian, German, and Russian. Some other plugin messages and action names still use English.

### New official website

The [Zotero Vim Plus website](https://zorrostardust.github.io/zotero-vim-plus/) is now live. Download the XPI, watch the existing demo on demand, and go straight to guides for PDF reading, annotations, library organization, and notes. The website, README, and guides offer the same nine language options. The site also works on mobile, so you can keep a guide open alongside Zotero.

### Install or update

Supports **Zotero 7–10** on macOS, Linux, and Windows. In Zotero, open **Tools → Plugins**, then use the gear menu to install `zoetero-vim-plus.xpi` from this release's assets. Existing users can also check for updates in the Plugins window.

## 简体中文

[项目主页](https://zorrostardust.github.io/zotero-vim-plus/zh-CN/) · [中文使用指南](https://zorrostardust.github.io/zotero-vim-plus/zh-CN/getting-started.html)

**Zotero Vim Plus 2.0** 把读论文、选文批注、整理待读文献和编辑笔记串在同一套键盘操作里。

### PDF 阅读与批注

- **Flash 选文。** 按 `Shift+V`，输入当前窗格里看得到的词或短语，再用提示字母选中匹配。按 `Enter` 可选中离视口中心最近的一项。已有选区时再次按 `Shift+V`，可以保留起点、移动选区的活动端。`Shift+C` 把文本光标放到匹配处。
- **实时选区提示。** 调整选区时，右下角会持续显示选中的字符数，并提示 `y` 复制、`i` 批注、`z` 标注和 `t` 翻译。翻译仍使用已配置的 Translate for Zotero 服务。
- **双栏阅读顺序。** 光标移动、Flash 和键盘选区更一致地遵循 PDF 的阅读顺序。按 `:` 打开命令面板，运行「切换只选正文」，可跳过识别到的页眉、页码、题注和脚注等内容。
- **八色高亮和下划线。** 按 `z` 查看颜色键，第二键用小写创建高亮，用大写创建下划线，例如 `zy` 和 `zY`。选中已有高亮或下划线时，也能用这些键改颜色或切换类型。按 `i` 添加批注后直接进入评论编辑框。选中已有批注后，`y` 复制摘录或文本批注的正文，`yy` 复制评论，`Esc` 清除批注选择。

### 跟随引用和定位图表

- **可见链接与批注。** 在 PDF 普通模式按 `f`，用字母提示打开文内链接、选中批注，或预览参考文献和外部链接。一组引用有多个目标时，可用 `Ctrl+j` / `Ctrl+k` 移动、`Space` 标记、`y` 复制。
- **查找图表。** 按 `Space f g` 可用图表编号、题注文字或页码搜索。定位成功后会短暂标出识别到的图表。PDF 目录会停靠在阅读窗格旁，可以边看目录边读正文。
- **原生阅读器设置。** 在 PDF 搜索框中，`Ctrl+j` 切换「全部高亮」，`Ctrl+k` 切换「区分大小写」，`Ctrl+l` 切换「全字匹配」。按 `Space r t` 打开 PDF 主题浮窗，再按 `f` 和提示字母应用主题。

**升级后值得留意的默认键位。** 上一条／下一条批注改用 `[a` / `]a`。`[f` / `]f` 跳转图，`[t` / `]t` 跳转表，`[s` / `]s` 跳转目录标题，`[m` / `]m` 跳转 Vim 标记。PDF 可视模式里选中词改用 `giw`，笔记里的 `viw` 照常可用。改过键位时，按 `Space /` 查当前绑定。

### 文献库、阅读分组和笔记

- **临时选择集。** 在条目列表按 `s` 收集条目，切换分类或筛选条件后集合仍保留。用 `Space s s` 检查目标，`Space s c` 清空。用 `Space t a` / `Space t r` 批量增删标签，或用 `Space c a` 把顶层条目加入同一文库的分类。集合为空时，这些操作使用 Zotero 当前选中的条目。
- **本机阅读分组。** `Space b c` 新建分组，`Space b a` 追加 PDF，`Space b l` 浏览分组并打开附件。分组和排序重启后仍保留。移出分组只移除列表里的记录，原 Zotero 条目和文件仍在。
- **笔记选择器与侧栏。** `Space n` 打开选择器，`Ctrl+k` 查看当前条目的笔记，`Ctrl+j` 查看全部笔记，`Ctrl+l` / `Ctrl+h` 在预览和列表之间切换。面板打开期间，两组笔记分别保留选中项和滚动位置。在 PDF 或侧栏笔记的普通模式按 `Space r n` 开关笔记侧栏。
- **条目搜索排序。** 多词查询横跨标题、创建者、年份和引用键等字段时，更稳定地优先显示精确匹配和完整词。

### 命令面板与设置

- 在文献库或 PDF 普通模式按 `:`，搜索命令后按 `Enter` 执行。按 `Space p` 直接打开键盘设置面板，用 `Shift+J` / `Shift+K` 切换设置页，按 `f` 显示操作提示。
- Zotero 原生插件设置按「常规、外观、阅读器、笔记、快捷键」分栏。「外观」页支持预览主题和自定义配色，经典主题的面板和模式提示也统一了颜色。
- 插件设置和常用操作名称提供英语、简体中文、西班牙语、日语、韩语、法语、意大利语、德语和俄语。部分界面提示和操作名称仍会显示英文。
