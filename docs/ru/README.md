# Руководство по Zotero Vim Plus

[Языки](../README.md) · [Проект](../../README.ru.md)

## Установка и язык

Скачайте [файл XPI](https://github.com/ZorroStardust/zotero-vim-plus/releases/latest/download/zoetero-vim-plus.xpi). В Zotero откройте менеджер дополнений через меню «Инструменты» и установите файл через меню с шестерёнкой. Поддерживаются Zotero 7–10. В настройках Zotero выберите русский язык в разделе **Zotero Vim Plus → Общие → Язык**.

## Чтение и аннотирование PDF

Щёлкните по странице. Используйте `j` / `k` для прокрутки и `h` / `l` для перехода между страницами. Нажмите `/` для поиска, подтвердите ввод клавишей `Enter` и переходите между совпадениями с помощью `n` / `N`. `Space f h` ищет по оглавлению, `Space f g` — по подписям к рисункам и таблицам, а `f` показывает подсказки для видимых ссылок и аннотаций. Чтобы изменить тему PDF, нажмите `Space r t`, затем `f` и введите показанные буквы.

Нажмите `v` и выберите подсказку, чтобы начать выделение. С помощью `Shift+V` можно ввести слово или фразу, видимые на экране, и выбрать совпадение. Клавиши `h` / `j` / `k` / `l` изменяют границы выделения. Счётчик в правом нижнем углу показывает число выделенных символов. `y` копирует текст, `i` добавляет комментарий, `zy` выделяет жёлтым, `zY` подчёркивает. `t` переводит выделение, если настроен Translate for Zotero. `[a` / `]a` выбирают предыдущую или следующую аннотацию.

## Библиотека и заметки

Ищите в библиотеке с помощью `Space f f` или в текущей коллекции с помощью `Space f b`. В списке записей `s` добавляет записи во временную подборку или удаляет их. Проверьте подборку через `Space s s` перед изменением тегов с помощью `Space t a` или `Space t r`. Создайте группу чтения через `Space b c` и откройте её через `Space b l`.

Откройте список заметок с помощью `Space n`. `Ctrl+k` показывает заметки текущей записи, `Ctrl+j` — все заметки. `Enter` открывает заметку, `Shift+Enter` открывает её в отдельной вкладке. `Space r n` показывает или скрывает боковую панель заметок в читалке. В редакторе `Esc` включает **NOTE NORMAL**, `i` позволяет вводить текст, а `Esc` возвращает в обычный режим.

## Сочетания клавиш

`Space /` показывает текущие сочетания, а `Space p` открывает настройки. Если клавиша не срабатывает, проверьте активную панель и режим. Чтобы изменить назначение клавиш, откройте **Сочетания клавиш** и нажмите **Применить сочетания** после редактирования.
