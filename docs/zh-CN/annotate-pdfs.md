# 选中文字和创建批注

[文档目录](../README.md) · [English](../en/annotate-pdfs.md)

打开带有可选文字的 PDF，点击页面，确认阅读器处于普通模式。

## 创建高亮

1. 按 `v` 进入可视模式。页面上可见的句首会出现字母提示。
2. 输入一个句首提示，展开句内的词级提示。再输入一次相同提示可从句首开始，也可以输入另一个提示来定位到某个词。输入时用小写字母。
3. 用 `w` / `b` 按词调整选区，或用 `j` / `k` 按行调整。按 `o` 可以改调选区的另一端。
4. 先按 `z`，再按 `y`，创建黄色高亮。单按 `y` 可以复制选中文字，按 `za` 可以高亮并打开批注评论编辑框。

挑选提示时，按 `Esc` 返回上一级。已经选中文字时，按 `Esc` 退出可视模式。要先放置文本光标，可在普通模式按 `c`，选一个字母提示，再在光标模式按 `v` 从该处开始选文。

## 回到已有批注

在 PDF 中按 `]a` / `[a` 选中下一条 / 上一条批注。PDF 页面和批注侧栏都会显示选中的批注。按 `i` 或 `Enter` 打开评论编辑框。编辑时按 `Enter` 换行，按 `Esc` 保存评论并返回普通模式。

选中批注后，按 `y` 复制高亮文字，快速按两次 `y` 复制评论。按 `dd` 会删除选中的批注，按之前先看清当前选中的是哪一条。要按颜色筛选批注侧栏，可用 `Zy`（黄）、`Zr`（红）、`Zg`（绿）、`Zb`（蓝）或 `Zp`（紫）。`Za` 清除筛选。

## 用 Flash 查找并选中可见文字

将焦点放在 PDF 上，按 `Shift+V`（大写 `V`），输入当前窗格里可见单词的一部分或一段短语。输入结果的提示字母，或点击提示标记，就能选中完整匹配。也可以按 `Enter` 选中距离视口中心最近的一项。选中后可以继续扩大选区、按 `y` 复制，或按 `zy` 高亮。

已有选区时，再按一次 `Shift+V` 可以定位选区的活动端，起点会保留。按 `Esc` 取消本次查找并恢复原选区。只想把文本光标移到匹配开头时，在普通模式或光标模式按 `Shift+C`。

输入 `giw` 可选中 PDF 选区活动端所在的词。

## 复制或翻译选文

在 PDF 可视模式下，按 `y` 复制选中文字，按 `yy` 复制整段，按 `#` 在 PDF 正文中查找当前选区。

要翻译选文，先安装并配置 [Translate for Zotero](https://github.com/windingwind/zotero-pdf-translate)。选中文字后按 `t`，插件会把选文发给配置的翻译服务。在 Translate for Zotero 中启用词典后，单词会优先查词典。弹窗中按 `j` / `k` 滚动，按 `y` 复制结果，按 `Esc` 回到原选区。

## 给选文加下划线或改已有批注

在可视模式按 `z` 并稍等，查看颜色快捷键。第二个键用小写创建高亮，用大写创建下划线。例如 `zy` 是黄色高亮，`zY` 是黄色下划线。

在普通模式按 `f`，再输入批注的提示字母，可以直接选中屏幕上的批注。选中高亮或下划线后，可以用同一套颜色键改颜色或切换类型。按 `Esc` 清除选中状态。
