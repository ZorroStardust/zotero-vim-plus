# 用 Vim 按键编辑 Zotero 笔记

[文档目录](../README.md) · [English](../en/edit-notes.md)

独立笔记标签页、文献库条目面板和阅读器的笔记侧栏都可以使用笔记 Vim 模式。点击编辑器内部，再按 `Esc`。看到 **NOTE NORMAL** 后就可以输入编辑命令。

## 试着改一个词

1. 在笔记中以插入模式输入一行文字，例如 `Status: "draft"`。如果现在是笔记普通模式，先按 `i` 开始输入。
2. 按 `Esc`，再用 `h` / `l` 把光标移到 `draft` 的某个字母上。
3. 输入 `ci"`，清除引号内的文字并进入插入模式。输入 `reviewed` 后按 `Esc`。原来的双引号会保留。

## 搜索和选中文字

- 在笔记普通模式按 `/`，输入要找的词并按 `Enter`。用 `n` / `N` 切换匹配项。
- 输入 `viw` 选中光标所在的词。按 `y` 复制选区，或按 `Esc` 退出可视模式。
- 在笔记编辑器里，`v` 按字符选择，`Shift+V`（大写 `V`）按逻辑行选择。自动折行仍算同一逻辑行。
- 在笔记普通模式中，用 `u` / `Ctrl+r` 撤销 / 重做。

如果编辑器一直处在普通打字状态，到 Zotero 设置中的 **Zotero Vim Plus → 模式**检查笔记 Vim 模式开关。它可以独立于阅读器模式启用。如果已经看到 **NOTE NORMAL**，命令仍然被打进笔记，见[故障排查](troubleshooting.md#vim-命令被打进笔记)。

## 边读论文边找笔记

在文献库或 PDF 阅读器中按 `Space n` 打开笔记布局面板。左侧列出当前条目的笔记和文库中的笔记，右侧预览选中的笔记。用 `j` / `k` 移动，用 `Ctrl+j` / `Ctrl+k` 在两组列表间切换。按 `Enter` 打开笔记，或按 `Shift+Enter` 在独立标签页打开。在 PDF 中按 `Enter` 会优先打开阅读器侧栏编辑器，方便对照正文。
