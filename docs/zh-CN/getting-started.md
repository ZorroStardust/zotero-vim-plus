# 安装 Zotero Vim Plus 并试用快捷键

[文档目录](../README.md) · [English](../en/getting-started.md)

Zotero Vim Plus 支持 macOS、Linux 和 Windows 上的 Zotero 7–10。

## 安装

1. 从[下载页](https://github.com/ZorroStardust/zotero-vim-plus/releases/latest)下载 `zoetero-vim-plus.xpi`。
2. 在 Zotero 中打开**工具 → 插件**，点击齿轮图标，选择**从文件安装插件**。
3. 选中下载的 XPI，按提示重启 Zotero，然后在插件窗口确认 **Zotero Vim Plus** 已启用。

手动更新时，从同一菜单安装新版 XPI。

要切换插件语言，在 Zotero 设置中打开 **Zotero Vim Plus → 常规 → 语言**。

## 在 PDF 中试用

1. 在 Zotero 中打开一篇 PDF，点击页面，让阅读器获得焦点。
2. 按 `j` 向下滚动，按 `k` 向上滚动。按 `/` 打开搜索，输入一个词后按 `Enter`，再用 `n` / `N` 切换匹配结果，按 `Esc` 关闭搜索。
3. 按下并松开 `Space`，再按 `/` 打开快捷键参考。输入按键或动作名称来查找，按 `Esc` 返回 PDF。

接下来可以[做第一条高亮](annotate-pdfs.md#创建高亮)或[编辑笔记](edit-notes.md)。要在 Zotero 文献库里搜索和归类，见[查找和整理文献](manage-library.md)。按键结果和预期不同时，先[检查焦点和模式](troubleshooting.md#按键没反应或控制了别的区域)。
