# 在文献库里查找和整理论文

[文档目录](../README.md) · [English](../en/manage-library.md)

先切到 Zotero 的文献库标签页。点击左侧分类树或中间条目列表，让按键作用于对应窗格。

## 浏览分类和条目

| 按键 | 结果 |
| --- | --- |
| `Space w h` / `Space w w` / `Space w l` | 将焦点移到分类树 / 条目列表 / 条目详情 |
| `j` / `k`、`gg` / `G` | 上下移动，或跳到第一行 / 最后一行 |
| 分类树中的 `h` / `l` | 折叠或返回上级分类 / 展开或进入条目列表 |
| `Enter` | 从分类树进入条目列表，或打开列表中选中的条目 |
| `Space o` | 打开选中条目的 PDF |

在分类树中按 `/` 筛选分类。较旧的 Zotero 会打开分类选择器。在条目列表中按 `/` 打开 Zotero 的快速搜索，输入时可用 `Ctrl+h` / `Ctrl+l` 切换搜索范围。按 `Enter` 返回筛选后的列表，或按 `Esc` 清空查询并返回。

## 找论文和复制引文

1. 按 `Space f f` 搜索当前文库，或按 `Space f b` 搜索当前分类。PDF 阅读器中也能打开这两个条目选择器。
2. 输入部分标题、作者、年份或引用键。用 `Ctrl+h` / `Ctrl+l` 切换「标题、创建者、年份」「所有字段和标签」和「所有内容」三种搜索范围。「所有内容」还查索引中的附件正文。用 `Ctrl+Shift+h` / `Ctrl+Shift+l` 按条目类型筛选，例如参考文献、附件、笔记或批注。
3. 按方向键选中结果。对于论文条目，按 `Enter` 在文献库里定位，按 `Ctrl+o` 打开。按 `Ctrl+y` 复制格式化引文，或按 `Ctrl+Shift+y` 复制引用键。

按 `Space b j` 查找已打开的标签页。可以输入显示的提示字母，也可以用方向键选中标签页后按 `Enter`。

## 批量切换彩色标签

先在 Zotero 中为标签设定颜色。将焦点放在条目列表，选中同一文库中的一个或多个条目。输入 `t1` 至 `t9` 切换对应位置的彩色标签。如果任何一个选中条目已有这个标签，快捷键会从所有选中条目移除它，否则会给全部选中条目加上它。输入 `t0` 会移除选中条目的全部彩色标签。

## 用临时选择集做批量整理

在条目列表按 `s`，把当前条目或 Zotero 多选中的条目纳入选择集。如果选中条目全都已在集合中，再按 `s` 会把它们移出。列表用彩色竖条标记已加入的条目。切换分类或筛选条件时，集合仍保留在当前窗口内。

1. 按 `Space s s` 检查集合，也能看到当前列表之外的条目。按 `Enter` 定位条目，或按 `Delete` 将它移出集合。回到文献库后按 `Space s c` 清空集合。
2. 按 `Space t a` / `Space t r` 添加或移除标签，或用 `Space c a` 将顶层条目加入同一文库的可编辑分类。
3. 确认前查看目标摘要。集合有条目时，这些操作作用于整个集合。集合为空时，操作作用于 Zotero 当前选中的条目。彩色标签快捷键 `t0` 至 `t9` 始终以 Zotero 当前选中条目为准。

## 保存一组待读 PDF

阅读分组记录一组 PDF 附件，保存在本机的 Zotero 配置中，重启后仍可打开。

1. 把论文加入选择集，或者清空集合后用 Zotero 多选。按 `Space b c` 新建分组，或按 `Space b a` 把 PDF 追加到已有分组。一个条目有多个 PDF 时，从中选一份。没有可用 PDF 的条目会被跳过。核对摘要后确认。
2. 按 `Space b l` 打开分组列表，选中分组后按 `Enter` 查看 PDF，再按 `Enter` 打开选中的 PDF。用 `Alt+↑` / `Alt+↓` 调整顺序。
3. 在分组列表中，按 `Ctrl+r` 重命名，或按 `Delete` 并确认删除分组。在组内按 `Delete` 可移出选中的 PDF。原 Zotero 条目和文件仍会保留。
