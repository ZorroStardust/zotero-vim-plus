# 阅读和定位 PDF

[文档目录](../README.md) · [English](../en/read-pdfs.md)

点击 PDF 页面，让阅读器获得焦点。下方按键用于普通模式。如果焦点在搜索框、目录或笔记里，先关闭对应界面或再次点击 PDF。

## 在论文里移动

| 按键 | 结果 |
| --- | --- |
| `j` / `k` | 向下 / 向上滚动 |
| `Ctrl+d` / `Ctrl+u` | 向下 / 向上滚动半页 |
| `h` / `l` | 跳到上一页 / 下一页 |
| `gg` / `G` | 跳到第一页 / 最后一页 |
| `5G` | 跳到第 5 页 |
| `Ctrl+o` / `Ctrl+i` | 在阅读位置历史中后退 / 前进 |

通过目录跳转等操作会留下阅读位置。想在滚动后精确回到某处，可以先按 `ma` 设标记，再按反引号和 `a` 跳回。按 `Space m` 查看已有标记。如果要在重启后保留标记，可在插件设置中开启标记持久化。标记通常保存在父条目的 Extra 字段，无法写入时则保存在本机设置中。

## 查找词语或章节

- 查找正文时，按 `/`，输入词语后按 `Enter`。用 `n` / `N` 切换匹配项，按 `Esc` 关闭搜索。
- 按标题查章节时，按 `Space f h`。PDF 有目录时，列表会定位到当前阅读的章节。输入部分标题，选中结果后按 `Enter` 跳转。
- 浏览目录树时，按 `Space e`。用 `j` / `k` 移动，用 `l` / `h` 展开或折叠章节。按 `Enter` 跳转，或按 `Esc` 关闭目录。

## 对照同一篇论文的两处内容

按 `Space -` 打开上下分屏。在新窗格里搜索或跳到另一章，原窗格可以用来对照。按 `Ctrl+j` 或 `Ctrl+k` 在两侧切换焦点，再按一次 `Space -` 关闭分屏。要左右分屏，按下 `Space` 后输入竖线键，再用 `Ctrl+h` / `Ctrl+l` 在两个 PDF 窗格之间切换。

如果想在当前窗格并排看两页，按 `Space s`。用 `Space S` 切换奇偶配对。配对按照 PDF 文件里的实际页序计算，封面也算一页。

## 跟随链接和查找图表

在 PDF 普通模式按 `f`，让屏幕上的链接、引文和批注显示字母提示。输入提示后，可以在文内跳转、选中批注，或预览参考文献和外部链接。在预览中按 `Enter` 打开选中的目标，按 `Esc` 返回。如果预览列出多条参考文献，用 `Ctrl+j` / `Ctrl+k` 移动、用 `Space` 标记，再按 `y` 复制已标记的条目。

按 `Space f g` 可用图表编号、题注文字或页码搜索。选中结果后按 `Enter` 跳转。也可以按目标类型依次跳转：

| 上一个 / 下一个 | 目标 |
| --- | --- |
| `[f` / `]f` | 图 |
| `[t` / `]t` | 表 |
| `[s` / `]s` | 目录标题 |
| `[m` / `]m` | 已设置的 Vim 标记 |
| `[a` / `]a` | 批注 |

在 PDF 搜索框输入时，`Ctrl+j` 切换「全部高亮」，`Ctrl+k` 切换「区分大小写」，`Ctrl+l` 切换「全字匹配」。回到 PDF 后，可以按 `:` 打开命令面板并运行「切换只选正文」，让 Flash 和键盘选区跳过识别到的页眉、页码、题注和脚注。再次运行可恢复可选文字的完整范围。

## 阅读 EPUB 和网页快照

点击 EPUB 或网页快照的正文，可以用 `j` / `k` 滚动，用 `/` 和 `n` / `N` 搜索，或用 `gg` / `G` 跳到开头或结尾。手册中的键盘选文和批注流程适用于 PDF。
