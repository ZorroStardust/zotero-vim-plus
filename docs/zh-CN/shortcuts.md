# 查找和修改快捷键

[文档目录](../README.md) · [English](../en/shortcuts.md)

## 查找当前绑定

1. 将焦点放在文献库、PDF 阅读器或处于普通模式的笔记里。
2. 按下并松开 `Space`，再按 `/`。可以按按键、动作或模式搜索。参考表会反映自定义绑定和解绑，按 `Esc` 返回。
3. 想边用边查组合键时，按一下 `Space` 并稍等。Spacekeys 会提示当前区域还能接哪些键。

## 常用默认键位

| 焦点 | 按键 | 结果 |
| --- | --- | --- |
| PDF 普通模式 | `j` / `k`、`h` / `l` | 滚动，或跳到上一页 / 下一页 |
| PDF 普通模式 | `/`、`Space f h` | 搜索正文，或搜索目录标题 |
| PDF 普通模式 | `v`、`c` | 进入可视模式选文，或进入光标模式移动文本光标 |
| PDF 可视模式 | `y`、`zy` | 复制选区，或创建黄色高亮 |
| 文献库条目列表 | `j` / `k`、`Enter` | 切换条目，或打开选中条目 |
| 文献库条目列表 | `/`、`Space f f` | 打开 Zotero 快速搜索，或打开插件的文库条目选择器 |
| 文献库分类树 | `/` | 筛选分类。在旧版 Zotero 中打开分类选择器 |
| 笔记普通模式 | `i`、`/`、`viw` | 开始输入、搜索笔记，或选中光标所在的词 |

## 修改绑定

1. 打开 Zotero 设置，进入 **Zotero Vim Plus → 按键绑定**。
2. 找到要修改的模式及动作，编辑按键单元格，或添加绑定。按键区分大小写。大写 G 写作 `G`，以空格开头的组合键可以写成 `<space>ff`。
3. 点击**应用绑定**。如需解绑，点该行的 **×**，再点击**应用绑定**。
4. 打开快捷键参考确认改动。如果改掉了 `Space /`，用新绑定打开参考，或在设置里查表。

`ci"` 等笔记编辑命令使用固定键位。如需关闭笔记 Vim 或启用其他阅读器模式，可在插件设置中打开**模式**。

文献库的搜索、标签和阅读分组见[文献库指南](manage-library.md)。`Shift+V` 在 PDF 和笔记中各有用途，见[Flash 选文](annotate-pdfs.md#用-flash-查找并选中可见文字)和[笔记选文](edit-notes.md#搜索和选中文字)。

## 用键盘运行命令和打开设置

在文献库或 PDF 普通模式中按 `:` 打开命令面板。输入动作名称，选中后按 `Enter` 执行。要查当前绑定，用 `Space /`。

在文献库、PDF 阅读器或笔记普通模式中按 `Space p` 打开设置面板。用 `Shift+J` / `Shift+K` 切换设置页，用 `Tab` 移动焦点，也可以按 `f` 后输入提示字母来选中控件。按 `Esc` 退出当前控件或关闭面板。修改快捷键后，点击**应用绑定**保存。

主题页可以预览各个预设，也有**自定义**配色。选中预设会修改 Vim Plus 控件和提示的颜色。自定义时可输入六位十六进制颜色，再应用配色。
