# Zotero Vim Plus 故障排查

[文档目录](../README.md) · [English](../en/troubleshooting.md)

## 安装后找不到插件

在**工具 → 插件**里确认 **Zotero Vim Plus** 已列出并启用。确认安装的是发布页附件里的 XPI。可以在 Zotero 的「关于」窗口查看版本，与[发布说明](https://github.com/ZorroStardust/zotero-vim-plus/releases)里的兼容范围核对。

## 按键没反应或控制了别的区域

1. 点击要操作的窗格。操作 PDF 时点击页面。操作笔记时点击编辑器内部，按 `Esc`，直到出现 **NOTE NORMAL**。
2. 如果搜索框或弹窗开着，先关掉再试。
3. 按 `Space /` 查看命令是否适用于当前区域和模式。如果改过键位，包括打开参考表的按键，可以去插件设置的**快捷键**页中核对。
4. 如果字母键仍然异常，先结束输入法组字，再切到直输状态重试。反馈时附上使用的输入法。

## Vim 命令被打进笔记

在 **Zotero Vim Plus → 笔记**中确认笔记 Vim 模式已启用。如果编辑器有命令面板打开，第一次按 `Esc` 可能只会关掉面板，再按一次并检查模式指示。已经看到 **NOTE NORMAL** 但移动命令仍然插入字母时，请注明问题出在独立笔记标签页、文献库条目面板还是阅读器笔记侧栏。

## 可视模式没有文字提示

找一页可以用鼠标选中文字的 PDF，再试一次 `v`。没有可选文字层的扫描 PDF 无法提供文字提示。也可以在插件设置的**阅读器**页中确认阅读器的可视模式已开启。

## 快捷键和指南不同

先把焦点放在要操作的窗格，再按 `Space /`，用动作名称查找当前绑定。例如，在笔记里，`Shift+V` 按行选择，在 PDF 中则打开 Flash。Flash 不可用时，可以在 PDF 中按 `v`，通过提示选中句首或单词。

## 反馈问题

请附上 Zotero 和 Vim Plus 的版本、操作系统、焦点所在窗格、模式、完整按键顺序和实际结果。若涉及改键、输入法或其他键盘插件，也请一并说明。[提交 GitHub Issue](https://github.com/ZorroStardust/zotero-vim-plus/issues)。
